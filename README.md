# 🌟 Project Overview

This project demonstrates how Machine Learning can help retail businesses analyze customer behavior and create customer groups for better marketing strategies.

The system clusters customers according to:

- 💰 Annual Income
- 🛒 Spending Score
- 📊 Purchase Behavior
